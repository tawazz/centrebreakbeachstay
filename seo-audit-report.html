If you only do one thing

Keep https://centrebreakbeachstay.com.au as the public URL, and make www permanently redirect to the matching apex URL.

The apex site is healthy and already publishes the preferred URL in its page signals. The www hostname currently has no address, so a visitor or old link that includes www cannot reach the site. A permanent redirect preserves that traffic while keeping one public address.

  1. Add www.centrebreakbeachstay.com.au as an alias in the DNS and hosting settings.
  2. Set a permanent redirect from each www path to the matching apex path. For example, send https://www.centrebreakbeachstay.com.au/activities/ to https://centrebreakbeachstay.com.au/activities/, not to the homepage. Message to the website manager: Please keep https://centrebreakbeachstay.com.au as the primary domain, add the www hostname as an alias, and permanently redirect every www URL to its matching apex URL. Please confirm that all five routes and both PDFs preserve their paths.
  3. Test the homepage and all four routes in a private browser window. Confirm the apex pages return 200, each www version redirects to the matching apex page, and Google Search Console uses https://centrebreakbeachstay.com.au/sitemap.xml. A sitemap is the page list that search engines read.

Small fixes, in order

Restore the www redirect path

The apex homepage and routes return 200. A direct request to https://www.centrebreakbeachstay.com.au/ returned a DNS resolution error, meaning the browser could not find an address for that hostname.

Fix: Add the www alias at the hosting provider and redirect it permanently to the matching apex URL. Keep all route paths and query strings intact.

Keep the sitemap date current

The live sitemap lists <lastmod>2026-08-29</lastmod> for all five content pages, while the latest page update was reviewed on 4 September.

Fix: Update each lastmod date when that page’s content changes. Keep the date tied to a real page edit rather than changing every date on every release.

Submit the apex sitemap after the host change

The sitemap contains five apex URLs and robots.txt points to https://centrebreakbeachstay.com.au/sitemap.xml.

Fix: After the www redirect is live, submit the apex sitemap in Google Search Console and inspect the homepage plus the four route pages.

Ask local partners for relevant links

The project has recorded 121 backlinks from 52 referring domains, other websites linking to the site, and 104 referring pages. The site can build on that base with links from tourism organisations, local activity operators, and nearby businesses.

Fix: Ask three partners that genuinely refer guests to link to /jurien-bay-accommodation/ or /green-head/ using the property name or page topic as natural link text.

Keep the new title set in future releases

The live titles now measure 59 characters on the homepage, 54 on activities, 53 on Green Head, 47 on accommodation, and 52 on the restaurant page. OpenSEO recorded no title-length issues.
